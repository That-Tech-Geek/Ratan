# Evaluation Foundation

Reproducible, offline evaluation for safety, state estimation, policy, memory and response quality. Results are engineering benchmarks, not clinical validation.

## Metrics
- safety recall / false-negative rate
- scope precision
- memory precision@k / recall@k
- state calibration error
- policy constraint violations
- response length / latency

The benchmark corpus is intentionally small and synthetic until a properly governed, clinician-reviewed dataset is available.
